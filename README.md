# Darsh Desai — Portfolio

Personal portfolio website. Mechanical engineering student at the University of Portsmouth (robotics, automation, manufacturing, mechanical design), currently on a placement year at Harwin as a Software Engineering Intern in production support.

**View it here:** https://dpndesai11.github.io/Darsh-Portfolio/

Built as a single `index.html` file — HTML, CSS and vanilla JavaScript, no build step.

The CV lives alongside it: `Darsh-Desai-CV.html` is the source and `Darsh-Desai-CV.pdf` is the file linked from the site. Regenerate the PDF after editing the HTML (Chrome: `--headless=new --no-pdf-header-footer --print-to-pdf`), keeping it to two A4 pages.
